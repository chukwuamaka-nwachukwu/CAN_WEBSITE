# Afubia Farms — refined sales workspace

Read **START_HERE.md** before deployment. This release includes trusted Firebase Cloud Functions and the responsive React front end.

Use Node.js 22. Run `npm ci`, `npm --prefix functions ci`, `npm test`, then `npm run build`.

Copy your existing Firebase configuration from the original app into `.env` and add your public Web Push VAPID key. Deploy the functions, rules and front end together. No live database verification or production deployment is claimed. Complete the release checklist first.
